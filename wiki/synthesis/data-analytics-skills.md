# Daten & Analytik Skills

## Übersicht
8 Skills von schnellen Lookups bis zu vollständigen statistischen Analysen.

## Skills

| Skill | Trigger | Zweck |
|-------|---------|-------|
| analyze | `/analyze` | Datenfragen beantworten — von Einzel-Metriken bis Berichten |
| explore-data | `/explore-data` | Datensatz profilieren: Form, Qualität, Muster |
| statistical-analysis | `/statistical-analysis` | Deskriptive Statistik, Trends, Ausreißer, Hypothesentests |
| sql-queries | `/sql-queries` | Korrektes, performantes SQL für alle Dialekte |
| write-query | `/write-query` | Optimiertes SQL mit Best Practices |
| data-visualization | `/data-visualization` | Visualisierungen mit Python (matplotlib, seaborn, plotly) |
| create-viz | `/create-viz` | Publikationsreife Visualisierungen |
| build-dashboard | `/build-dashboard` | Interaktives HTML-Dashboard (selbstständig im Browser öffenbar) |

## Wann welcher Skill?
```
Schnelle Frage         → /analyze
Datensatz verstehen    → /explore-data
Statistik brauchen     → /statistical-analysis
SQL schreiben          → /sql-queries oder /write-query
Visualisierung         → /data-visualization oder /create-viz
Executive Dashboard    → /build-dashboard
```
