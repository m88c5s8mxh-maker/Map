# superpowers

**Install:** `npx claude code plugin add obra/superpowers`  
**Typ:** Community Plugin  
**Kategorie:** [[engineering-skills]]

## Zweck
Pre-Coding Planning Loop — Research, Spec, Plan, Test, dann Build. Claude hört auf zu raten und denkt wie ein Senior Dev.

## Workflow
1. **Research** — Verstehe das Problem vollständig
2. **Spec** — Definiere was gebaut werden soll
3. **Plan** — Architektiere die Lösung
4. **Test** — Definiere wie Erfolg aussieht
5. **Build** — Erst jetzt Code schreiben

## Installation
```bash
npx claude code plugin add obra/superpowers
```
