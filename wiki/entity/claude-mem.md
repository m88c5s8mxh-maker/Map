# claude-mem

**Install:** `npx claude-mem install`  
**Typ:** Community Plugin  
**Kategorie:** [[knowledge-productivity-skills]]

## Zweck
Persistentes Gedächtnis für Claude Code — captured, compressed, re-injected. Kein Re-Explaining mehr zwischen Sessions.

## Wie es funktioniert
- Captures wichtige Kontext-Informationen aus Sessions
- Komprimiert diese effizient
- Injiziert sie beim Start neuer Sessions automatisch
- Eliminiert das manuelle Wiederholen von Kontext

## Installation
```bash
npx claude-mem install
```
