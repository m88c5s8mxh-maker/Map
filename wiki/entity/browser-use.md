# browser-use

**Install:** `npx claude code plugin add browser-use/browser-use`  
**Typ:** Community Plugin (kein SKILL.md)  
**Kategorie:** [[engineering-skills]]

## Zweck
Gibt Claude Kontrolle über einen echten Browser — Buttons klicken, Forms ausfüllen, Screenshots machen, parallele Sessions. Kein API nötig.

## Fähigkeiten
- Browser-Steuerung (Klicken, Tippen, Navigieren)
- Form-Ausfüllung automatisiert
- Screenshots zur Verifikation
- Parallele Browser-Sessions
- Kein externer API-Key erforderlich

## Installation
```bash
npx claude code plugin add browser-use/browser-use
```
