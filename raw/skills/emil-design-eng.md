# Emil Kowalski – Design Engineering Skill

Skill encodes Emil Kowalski's design engineering philosophy.
Autor von Sonner (13M+ npm downloads/week) und Vaul.

## Aktivierung
```
npx skills add emilkowalski/skill
```

## Kerninhalt
- Animations-Entscheidungsrahmen (wann, welches Easing, wie schnell)
- Spring-Animationen vs. duration-based
- Component-Prinzipien (Buttons, Popovers, Tooltips, Stagger)
- clip-path für Animationen
- Performance-Regeln (transform+opacity only, CSS > JS under load)
- Review-Checkliste mit Before/After Tabelle

## Ressourcen
- Kurs: [animations.dev](https://animations.dev)
- Easing: [easing.dev](https://easing.dev)
