# UI UX Pro Max — Design Intelligence Skill

Zwingt Claude zu echter Design-Richtung bevor irgendein Code entsteht. Typography, Color Systems, Animations — alles intentional.

## Was es tut
- **57 Font-Pairings** — kuratierte Typography-Kombinationen mit Google Fonts Import
- **25 Chart-Typen** — für Dashboards und Analytics
- **15 Tech-Stacks** — React, Next.js, Astro, Vue, Nuxt, Svelte, SwiftUI, React Native, Flutter, HTML+Tailwind, shadcn/ui, Jetpack Compose, Angular, Laravel
- **99 UX Guidelines** + **161 Reasoning Rules** für Design-System-Generierung
- **Design System Generator** (v2.0) — analysiert Project Requirements, generiert komplettes Design System in Sekunden

## Install
```bash
npx claude code plugin add nextlevelbuilder/ui-ux-pro-max-skill
```

## Verbotene Fonts (banned)
Inter, Roboto, Arial, System-Fonts, Space Grotesk — alles Generisches ist verboten.
Stattdessen: unerwartete Pairings mit Display-Font + raffiniertem Body-Font.

## Pre-Delivery Checks
Validiert automatisch gegen häufige UI/UX Anti-Patterns bevor Code geliefert wird.

## Wann nutzen
- Neues UI-Projekt starten
- Design System für ein Produkt definieren
- Wenn Claude "generisches AI-Design" produziert
