# Everything Claude Code — Agent Harness System

Das kompletteste Claude Code Setup-Paket. Entwickelt über 10+ Monate intensiver täglicher Nutzung beim Bauen echter Produkte.

## Was es tut
Ein vollständiges Agent-Harness-System mit:
- **Skills** — spezialisierte Fähigkeiten die lazy-geladen werden (~100 Token im Scan, <5k Token aktiviert)
- **Instincts** — automatische Verhaltensregeln ohne explizite Aufforderung
- **Memory Optimization** — Kontext-Management über Sessions hinweg
- **Security Scanning** — eingebaute Sicherheitsprüfungen
- **Research-First** — zuerst verstehen, dann bauen

## Install
```bash
npx claude code plugin add affaan-m/everything-claude-code
```

## Token-Effizienz
- Skill-Scan: ~100 Token (nur Metadata)
- Skill-Aktivierung: <5k Token (vollständiger Content)
- Bundled resources: nur bei Bedarf laden

## Kompatibel mit
Claude Code, Codex, Opencode, Cursor und mehr.

## Kern-Features
- Tkinter Dashboard GUI
- Java Spring Boot Skills
- Session Management mit Continuous Learning
- SQLite-basiertes Gedächtnis
