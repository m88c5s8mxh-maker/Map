# Ablage: Ideen

Noch nicht umgesetzte Vorschläge hier ablegen — eine Datei pro Idee, kurz.

Wird beim nächsten `/obsidian-wiki ingest --batch` ins Wiki übernommen und
landet über `graphify . --update` im Graph. Ideenseiten im Wiki tragen den
Tag `#idee`, damit sie in Obsidian per Suche `tag:#idee` alle auf einmal
auftauchen.

Ideen, die in einer Claude-Session entstehen, werden von der
Session-Erfassung automatisch als Ideenseite abgelegt — siehe `CLAUDE.md`.

Sinnvoll pro Datei: Idee in einem Satz, Warum, was dagegen spricht, nächster
kleinster Schritt zum Prüfen.
