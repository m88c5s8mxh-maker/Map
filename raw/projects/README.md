# Ablage: Projekte

Notizen zu laufenden Vorhaben hier ablegen — eine Datei pro Projekt.

Wird beim nächsten `/obsidian-wiki ingest --batch` ins Wiki übernommen und
landet über `graphify . --update` im Graph.

Projekt-Zwischenstände aus Claude-Sessions kommen automatisch hierher
verlinkt: die Session-Erfassung (`scripts/session-capture.sh`) legt den
Mitschnitt in `raw/sessions/` ab und erzeugt bei Tier 2 eine Projektseite
in `wiki/`. Siehe [[Session-Erfassung]] bzw. `CLAUDE.md`.

Sinnvoll pro Datei: Ziel, aktueller Stand, nächste Schritte, offene Fragen.
